# pfa-week02
Week 2 programming for animators homework assingment.

## What it does now (Route B level-up)

Chandelier Generator builds parametric placeholder chandeliers for env/lighting blockouts — a problem I kept hitting where hand-modeling each fixture killed pacing. I solved it with one tool covering two styles (round torus-ring and square cube-frame) that scales cleanly: 1–5 tiers, 3–12 arms, filler lights on the support plus an inner center ring with its own height/spread controls, and three art-directable materials (metal / trim hardware / glowing lights with brightness). At 9am Sep 15 this was a single static prop; now it's N arms × M tiers with handled inputs, one-click undo, and group-only delete, so it survives a stranger's scene.
